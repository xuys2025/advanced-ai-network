# 兼容字段

`values.json` 集中保存必要的原始兼容字段，值使用 UTF-8 Base64。域名、签名主体、程序路径和测试输入在这里维护，公开文案使用产品代称。

这是可逆编码，目的是统一管理名称。匹配时仍使用原始字节，签名验证和规则范围保持准确。

修改映射后，在仓库根目录运行生成器，再重新构建。

```powershell
node .\compatibility\generate.cjs
```

生成器输出 C# 常量、C 宏、JavaScript 常量和 PowerShell 辅助函数。常量采用转义字面量，能够用于编译期常量和原生字符串拼接。生成文件已纳入版本库，普通 C# 构建可以直接使用它们。

安装器从映射中还原规则种子。测试输入只还原到 `Sources/build` 下的临时目录。第三方对应源码随 Release 的独立归档提供，恢复方式见该归档说明。
